# AWS S3 Static Website Hosting

## Project Overview

This project demonstrates how to host a static portfolio website using **Amazon Simple Storage Service (Amazon S3)**. The website was deployed on AWS cloud infrastructure and made publicly accessible through the S3 Static Website Hosting feature.

## Objective

The objective of this project was to:

* Create an Amazon S3 bucket
* Upload website files to the bucket
* Configure Static Website Hosting
* Apply bucket policies for public access
* Deploy a portfolio website on AWS Cloud
* Access the website through a public URL

## Technologies Used

* Amazon Web Services (AWS)
* Amazon S3
* HTML5
* CSS3
* Static Website Hosting

## Project Workflow

### Step 1: AWS Account Setup

Created and configured an AWS account with Free Plan access.

### Step 2: S3 Bucket Creation

Created a unique Amazon S3 bucket to store website files.

### Step 3: Website Development

Prepared static website files including:

* index.html
* style.css
* Images and assets

### Step 4: Upload Website Files

Uploaded all website files to the S3 bucket.

### Step 5: Enable Static Website Hosting

Configured the bucket for Static Website Hosting and specified:

* Index Document: `index.html`

### Step 6: Configure Public Access

Modified bucket permissions and added a bucket policy to allow public read access.

### Step 7: Website Deployment

Accessed the website using the S3 Website Endpoint URL.
