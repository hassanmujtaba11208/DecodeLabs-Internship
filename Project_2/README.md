# AWS EC2 Web Server Deployment

## Project Overview
This project demonstrates the deployment and management of an AWS EC2 Ubuntu instance.

## Technologies Used
- AWS EC2
- Ubuntu Linux
- Apache2
- SSH
- HTTP

## Tasks Performed
1. Created EC2 instance
2. Configured Security Groups
3. Connected through SSH
4. Installed Apache2
5. Deployed a sample webpage
6. Verified public accessibility

## Output
The deployed web page was successfully accessed through the EC2 public IP address.

## Learning Outcomes
- AWS EC2 Management
- Linux Administration
- Security Group Configuration
- Web Server Deployment
- SSH Connectivity
